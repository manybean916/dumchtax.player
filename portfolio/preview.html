WHAT IS DUMCHTAX PLAYER?
사진 한 장을 찍으면 Gemini AI가 그 순간의 무드를 읽고, 어울리는 음악을 YouTube에서 찾아 재생합니다. 폴라로이드와 LP 바이닐의 아날로그 감성 속에서 디지털 음악 경험을 새롭게 정의합니다.

02 / PROBLEM SPACE
WHY DOES THIS
NEED TO EXIST?
01
선택의 피로감
Decision Fatigue
플레이리스트 탐색에 지쳐 음악을 듣지 않는 사용자. 알고리즘 추천은 정확하지만 감성적 연결이 없다.
02
휘발되는 추억
Ephemeral Moments
사진과 그 순간의 감정은 기억되지만, 그때 들었던 음악과의 연결은 사라진다. 기억을 아카이빙할 도구가 없다.
03
아날로그 감성의 결핍
Missing Analog Soul
스트리밍 서비스는 편리하지만 음악을 '소유'하는 경험, 물성이 있는 감각을 줄 수 없다. 감성적 여백이 없다.

03 / SOLUTION
DUMCHTAX
SOLVES THIS.
◈
Multimodal 감성 매칭
사진 → Gemini Vision API → 무드 키워드 추출 → YouTube 검색. 알고리즘이 아닌 당신의 '지금 이 순간'이 플레이리스트를 만든다.
P0 CORE
◉
오브제 중심 아카이빙
폴라로이드 형태의 카드가 LIBRARY에 쌓인다. 사진 + 음악 + 순간을 하나의 오브제로 묶어 저장하고 재생한다.
P0 CORE
◫
아날로그 인터페이스
LP 회전, 아날로그 페이더 내비게이션, 폴라로이드 인화 애니메이션. 디지털이지만 손으로 만지는 것처럼 느껴지는 UX.
P1 DELIGHT
◬
Zero Friction Onboarding
API 키 없이도 데모 모드로 즉시 사용 가능. 설정은 설정 모달 하나에서 끝난다.
P2 ACCESS

10 / KEY SCREEN — PLAYER
PLAYER
THE MUSIC STARTS
IU — 밤편지
⏮ ▶ ⏭
LP 회전 애니메이션
재생 시 1.8s/rev 시계방향 회전. 일시정지 시 즉시 정지. 중앙 썸네일도 함께 회전.
ACCENT GLOW
LP 뒤에 accent 색상 glow 효과. 음악이 켜진 상태임을 공간으로 표현.
♡ HEART BUTTON
폴라로이드 우측 상단 빈 하트. 저장 시 #913439 fill. 다시 탭하면 저장 취소.
VOLUME FADER
수직 페이더로 볼륨 조절. YouTube IFrame API volume() 연동.
오디오 전용 재생
YouTube IFrame을 -400px 오프스크린 배치. 화면은 LP + 폴라로이드만 보임.
