# Dumchtax Player — 디자인 시스템 (Design System)

> 콘셉트: **아날로그 필름 암실(darkroom) + LP 턴테이블**. 종이 질감의 밝은 바탕 위에 잉크 블랙 타이포와 단 하나의 필름 레드 액센트. 모든 조작은 실물 기기의 물성을 흉내 낸다.

토큰의 단일 출처(single source of truth)는 [`styles.css`](../styles.css)의 `:root`이며, 이 문서는 그 값을 정리·설명한다.

---

## 1. 디자인 원칙

1. **물성 우선(Tactile-first)** — 버튼·리스트가 아니라 카메라·LP·페이더·로터리 노브를 조작한다. 드래그·회전·햅틱으로 조작감을 만든다.
2. **종이 위의 잉크(Paper & Ink)** — 밝은 종이 바탕(`#f5f5f0`) + 잉크 블랙 텍스트. 다크 서페이스는 기기(LP·카메라 렌즈) 표현에만 국소적으로 쓴다.
3. **단일 액센트(One accent)** — 필름 레드 `#913439` 하나만 강조에 쓴다. 녹화 점, 저장된 하트, 활성 레이블 등 "의미 있는 상태"에만.
4. **아날로그 그레인(Grain)** — 미세한 radial-gradient 노이즈로 종이·필름 질감을 상시 유지한다.
5. **모션은 기계처럼(Mechanical motion)** — 인화·토출·회전·낙하 등 실제 기기의 물리 동작을 은유한다. 장식적 트랜지션은 지양.

| 토큰 | 값 |
|---|---|

## 3. 타이포그래피

두 개의 대비되는 서체로 "손글씨 캡션 vs 기계식 라벨"을 표현한다.

| 역할 | 토큰 | 폰트 |
|---|---|---|
| 스크립트(감성) | `--font-script` | `"Caveat", "Nanum Pen Script", cursive` |
| 모노(기계) | `--font-mono` | `"JetBrains Mono", "Courier New", monospace` |

- **앱 타이틀 / 폴라로이드 캡션** → Caveat, weight **500** (둘의 굵기를 의도적으로 일치시킴).
- **본문 / 라벨 / 버튼 / 상태** → JetBrains Mono. 대문자 + `letter-spacing`으로 계기판 느낌.

### 스케일 (실측)
| px | 용도 |
|---|---|
| 28 | 앱 타이틀 (script) |
| 18–19 | 섹션/카운트 강조 |
| 13–14 | 버튼·본문 라벨 |
| 10–11 | 캡션·메타(눈금/ISO 등) |
| 9 | 초소형 메타 |

| 토큰 | 값 |
|---|---|
| `--space-xs` | 4px |
| `--space-sm` | 8px |
| `--space-md` | 16px |
| `--space-lg` | 24px |
| `--space-xl` | 32px |
| `--space-2xl` | 48px |
| `--header-h` | 56px |
| `--nav-h` | 84px |

- **앱 셸**: `max-width 420px`, `height 100dvh`, 중앙 정렬, 바깥은 암실톤(`#2a2a28`) + 큰 드롭섀도로 "손에 든 기기" 느낌.
- **페이지 뷰포트**: `width:300%` 가로 트랙 3장을 `transform`으로 슬라이드 (페이더와 동기).
- **그레인**: `#app`에 `radial-gradient(rgba(0,0,0,.025) 1px, transparent 1px)` 5px 타일.

## 5. 라운딩 (Radius) 언어

| 값 | 용도 |
|---|---|
| `50%` | 렌즈·노브·LP·도트 등 원형 기기 부품 |
| `2–5px` | 폴라로이드 프레임·작은 버튼 |
| `9–10px` | 카드·패널 |
| `20–22px` | 카메라 바디·큰 물리 오브젝트 |
| `22px 0 0 22px` | 카메라 그립 등 한쪽만 둥근 실물 형태 |

## 6. 핵심 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| **로고** | 셔터 조리개(iris) + 사운드웨이브 + 세그먼트 베젤 + 재생 삼각형이 결합된 인라인 SVG. `currentColor`(잉크)로 렌더, 36px. |
| **아날로그 페이더 내비게이션** | 드래그 1:1 콘텐츠 동기화, 눈금 통과 시 햅틱, 자석 스냅, 활성 레이블 weight 보간(90→10 그레이). HOME/PLAYER/LIBRARY 라벨·아이콘은 0%/50%/100%에 절대 정렬. |
| **인스탁스풍 카메라** | CSS-only 아이보리 바디(리브 그립·렌즈 링·다크 디스크·배럴). 사진이 여기서 "토출"된다. |
| **폴라로이드** | 프레임 + 이미지 + 손글씨 캡션. 저장 시 우측 상단 ♡가 액센트로 채워짐. |
| **LP 디스크** | 중앙 썸네일 + 홀. 재생 중 회전, 정지 시 그 자리에서 멈춤. |
| **볼륨 로터리 노브** | 상대 델타(encoder) 방식으로 360° 무한 회전, 최대/최소에서도 조작 유지, 값은 0–100 클램프. |
| **Now-playing 미니 필** | PLAYER 밖 페이지에서 재생 중일 때 노출되는 작은 팝업(회전 디스크 + EQ 바). |
| **갤러리 조명** | LIBRARY 상단의 중립 화이트 LED 스트립(머신드 엔드캡). |
| **Scattered Memories** | 랜덤 각도·위치 폴라로이드 더미. 자유 드래그(위치 영속), 탭 시 재생 복원. |
| **토스트** | 하단 중앙, 페이드+슬라이드 인. |

## 7. 모션 규격 (Keyframes)

`styles.css`에 정의된 실제 애니메이션:

| 이름 | 역할 | 특징 |
|---|---|---|
| `developHold` → `developFinish` | 폴라로이드 인화 2단계 | 분석 완료 전까지 흑백/blur 유지 → 완료 후 컬러로 현상 (총 ~2.4s) |
| `grainfade` | 필름 그레인 소멸 | opacity 0.4 → 0 |
| `eject` / `landbounce` | 폴라로이드 토출·착지 | translateY + 바운스 |
| `lpspin` | LP 회전 | 360°/**1.8s** linear, 재생 중에만 `animation-play-state: running` |
| `heartpop` | 저장 하트 팝 | scale 1.3 피크 |
| `drop` | 라이브러리 낙하 저장 | 폴라로이드가 보드로 떨어짐 |
| `nppillin` / `npeq` | 미니 필 등장·EQ 바 | 이퀄라이저 바 상하 |
| `flashfire` | 셔터 플래시 | opacity 0→0.85→0 (35% 피크) |
| `dotpulse` / `blink` | REC 점 맥동·점멸 | 상태 라이브니스 |
| `toastin` | 토스트 진입 | opacity + translateY |

**모션 원칙**: 지속시간은 물리 은유에 맞춘다(인화는 느리게, 팝은 빠르게). 이징은 기본 linear/ease로 기계적 정확성을 유지하고, 페이더 스냅만 속도(플리킹 300px/s) 기반 관성 처리.

---

## 8. 상호작용 & 햅틱

- **드래그**: 페이더·Scattered 폴라로이드는 포인터와 1:1로 붙는다.
- **햅틱**: 페이더가 눈금을 통과할 때 `navigator.vibrate`로 진동(지원 기기).
- **자석 스냅**: 놓았을 때 거리 또는 플리킹 속도(300px/s) 기준으로 가장 가까운 페이지에 스냅.
- **탭 타깃**: 실물 부품(노브·하트·카드)은 손가락에 맞춰 충분히 크게.

---

## 9. 이 시스템을 확장할 때

- 새 색이 필요하면 먼저 **잉크 명도 단계**로 해결을 시도하고, 강조는 **오직 `--color-accent`** 로 표현한다. 두 번째 액센트를 추가하지 않는다.
- 새 오브젝트는 위 **라운딩 언어**(원형=부품 / 큰 라운드=바디)를 따른다.
- 새 모션은 **실물 물리 은유**가 있어야 한다. 순수 장식 트랜지션은 이 시스템의 톤과 충돌한다.
- 토큰은 반드시 `styles.css :root`에 추가하고, 하드코딩 색·px를 컴포넌트에 직접 쓰지 않는다.
