# Dumchtax Player — 사용 맥락 (Usage Context)

> 사진 한 장이 음악이 되는 순간. 폴라로이드 × LP 감성의 모바일 뮤직 플레이어.

---

## 1. 한 줄 정의

사용자가 찍거나 고른 **사진의 무드를 AI가 읽어**, 그 분위기에 맞는 음악을 **YouTube에서 찾아 재생**하고, 마음에 든 조합을 **폴라로이드처럼 라이브러리에 수집**하는 감성 웹앱.

## 2. 왜 만들었나 (Problem)

- 음악 앱은 "무엇을 들을지" 정하는 일을 사용자에게 떠넘긴다. 무드는 있는데 검색어가 없다.
- 사진에는 이미 그 순간의 공기·색·분위기가 담겨 있다. 이걸 **음악 추천의 입력값**으로 쓰면, 검색 없이 그 순간에 어울리는 곡을 만날 수 있다.
- 스트리밍 UI는 대개 리스트·그리드로 기능적이다. 여기서는 **아날로그 기기(폴라로이드 카메라·LP·페이더)를 조작하는 물성**을 전면에 둬서, 추천을 "받는" 게 아니라 "현상하고 재생하는" 경험으로 바꾼다.

## 3. 누구를 위한 것 (Audience)

- 무드 기반으로 음악을 발견하고 싶은 모바일 사용자
- 사진·필름·LP 같은 아날로그 감성에 반응하는 사용자
- 포트폴리오 관점에서는 **인터랙션 디자인 + AI 파이프라인 + 물성 UI**를 한 화면에서 보여주는 데모

## 4. 플랫폼 / 기술 전제

| 항목 | 값 |
|---|---|
| 형태 | 정적 웹앱 (프레임워크 없음, Vanilla JS) |
| 대상 | 모바일 세로 (최대 폭 420px 컨테이너) |
| 파일 | `index.html` · `styles.css` · `app.js` 3개 |
| 서버 | 임의 정적 서버 (`python3 -m http.server 4173`) |
| 외부 API | Google Gemini(무드 분석) · YouTube Data API v3(음악 검색) · YouTube IFrame API(재생) |
| 저장소 | 브라우저 `localStorage` (라이브러리·API 키) — 서버·계정 없음 |

## 5. 핵심 사용자 여정 (Primary Flow, P0)

```
사진 선택/촬영
   ↓  셔터 플래시 + 폴라로이드 인화 애니메이션 (흑백→컬러, 약 2.4s)
Gemini 무드 분석  ──(실패)──▶ 시간대 기반 폴백 무드
   ↓
YouTube 음악 검색 (audioScore 랭킹으로 "음원" 우선)
   ↓  페이더가 PLAYER로 자동 슬라이드
LP 회전 + 재생
   ↓  폴라로이드 우측 상단 ♡ 탭
페이더가 LIBRARY로 자석 이동 + 폴라로이드 낙하 저장 (하트 #913439로 채워짐)
   ↓
라이브러리 카드 탭  ──▶  그 사진·곡 조합 그대로 재생 복원
```

## 6. 세 개의 페이지 (Mental Model)

아날로그 **페이더(fader)** 한 개로 세 페이지를 오간다. 페이더 노브가 콘텐츠와 1:1로 움직이고, 눈금을 지날 때 햅틱이 울리며, 놓으면 가장 가까운 페이지로 자석처럼 스냅한다.

| # | 페이지 | 역할 | 대표 오브젝트 |
|---|---|---|---|
| 0 | **HOME** | 사진 입력 + 현상 | 인스탁스풍 카메라, 토출되는 폴라로이드 |
| 1 | **PLAYER** | 재생 + 저장 | 회전하는 LP, 볼륨 로터리 노브, 폴라로이드+하트 |
| 2 | **LIBRARY** | 수집한 순간들 | 갤러리 조명, 흩뿌려진(Scattered) 폴라로이드 더미 |

## 7. 상태·데이터

- `state.library` — 저장된 `{photo, track, label, angle, pos}` 배열, `localStorage["dumchtax_library"]`에 영속.
- `state.results` / `state.trackIndex` — 현재 무드에 대한 검색 결과와 재생 위치.
- 저장 시 캡션(`곡명 — 아티스트`)을 **`label`로 프리즈**해서, 나중에 재생 복원해도 라벨이 흔들리지 않게 한다.

## 8. 폴백 & 무키(no-key) 동작

견고함을 위해 모든 외부 의존은 폴백을 갖는다.

| 상황 | 동작 |
|---|---|
| API 키 없음 | **데모 모드** — 시간대 기반 무드 + 데모 트랙(Lofi 라디오) 재생 |
| Gemini 분석 실패 | 시간대별 웰컴 플레이리스트로 폴백 |
| `gemini-2.5-flash` 오류 | `gemini-2.0-flash`로 폴백 |
| 특정 음원 재생 불가 | 다음 트랙으로 자동 스위칭 |

## 9. 프라이버시

- 사진은 업로드 즉시 클라이언트에서 압축되어 **Gemini 분석 요청에만** 쓰이고, 앱 서버에 저장되지 않는다 (앱에 서버가 없다).
- API 키·라이브러리는 사용자 브라우저의 `localStorage`에만 남는다.

## 10. 실행

```bash
cd dumchtax-player
python3 -m http.server 4173
# → http://localhost:4173 (모바일 사이즈 권장)
```

우측 상단 ⚙️에서 Gemini / YouTube Data API 키를 입력한다. 키가 없으면 데모 모드로 즉시 체험 가능.

| 키 | 용도 | 발급처 |
|---|---|---|
| Gemini API Key | 업로드 사진 무드 분석 | https://aistudio.google.com/apikey |
| YouTube Data API Key | 무드 기반 음악 검색 | https://console.cloud.google.com (YouTube Data API v3 활성화) |
